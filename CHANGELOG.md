# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0

* **Initial Release**
  * Interactive feature scaffold generator supporting **Clean Architecture**, **MVVM**, and **MVC**.
  * Dynamic boilerplate generator for custom Flutter themes (`AppTheme`, widget themes, colors).
  * Device helpers and context extension generation (`UDeviceHelper`, `UDeviceExtension`).
  * Project diagnostic tool command: `ftool doctor`.
  * Visual file and folder tree generator command: `ftool tree`.
  * Command-line argument parsing and help guide: `ftool --help`.
